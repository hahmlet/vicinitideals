Sec. 17.30.10. - Zoning Map.


The Zoning Map is incorporated herein and is deemed as much a part of this Code as if fully set forth.
If a conflict appears between the Zoning Map and the written portion of this Code, the written portion shall control.
The map and each amendment shall remain on file in the City's document archives.

The boundaries of all districts are established as shown on the Zoning Map, which is made a part of this Code.
All notations and references and other matters shown shall be and are hereby made part of this Code.

(Ord. No. 2024-01, § 1(Exh.
A), 2-20-2024)

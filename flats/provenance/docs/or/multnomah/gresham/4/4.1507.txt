4.1507  PERMITTED USES
Table 4.1507 lists those uses that are permitted in the Springwater Residential Sub-districts.
• P = Permitted use
• L = Use is permitted, but is limited in the extent to which it may be permitted
• NP = Use not permitted
• SUR = Use permitted subject to a Special Use Review
Each of these uses must comply with the land use district standards in Section 4.1500 and all other applicable requirements of the Community Development Code.

The county map copy

Every dated download of the county map the screen has read, which one is in use, and what stands between a refreshed copy and the site showing it. Nothing here updates on its own: a refresh is taken by hand, lands beside the copy in use, and is shown only after someone says promote. The same goes for a re-screen of the copy in use (the rules or the screen changed, the map did not): it lands as a waiting run on the copy's card and is shown only when promoted. The rule since 2026-09-19: the agent promotes when the gate is clean; anything with a warning waits for Steph. Since 2026-09-22 one warning does not wait: a zone code nobody has ruled on. The copy goes live, the code is written down within the week, and until then only the lots in that code sit — shown as a new zone under evaluation, never green and never red.

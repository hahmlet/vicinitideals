canopy-scout-ab

WHY: the FLATS lot screen (a tool that says whether a fixed-size 4-unit townhome can be placed on a lot) is about to use a public tree-canopy map to release about 430 Portland lots in the Johnson Creek Basin plan district (Portland City Code 33.537) that are held back because nothing measures trees. A lot is released only if the map shows no tree canopy over its parking area. If the map wrongly shows "no canopy", a lot gets a false GREEN -- the worst error this project can make. So the resolution (cell size), the date, and how the layer marks no-data matter most.

TASK: find the best free tree-canopy raster covering outer SE Portland (Johnson Creek, Lents, Powellhorst, Pleasant Valley). Check at least: Metro RLIS "Canopy 2019" (ArcGIS item b6da4ea243df4ba492d47860964cf2b5), Metro RLIS "C-CAP Land Cover" (item 8b89f2c933894056a02fd3c2d8a48f31), any City of Portland canopy product, DOGAMI LiDAR-derived canopy height, and anything newer than 2021. For each give: publisher, exact name, download or service URL, acquisition date, cell size, value meanings (which values mean tree / not tree / no data), CRS, licence, download size. The single most wanted fact: the CELL SIZE of Metro "Canopy 2019" -- look in the item's metadata (https://www.arcgis.com/sharing/rest/content/items/<id>?f=json and its /info/metadata/metadata.xml), the RLIS Discovery page, and Metro's published canopy reports.

ANSWER FORM (under 350 words): a table with one row per candidate (columns as listed), then "PICK:" one line with the reason in false-green terms, then "CANOPY 2019 CELL SIZE:" value + SEEN/INFERRED + where, then "LOOKED:" the places checked.

orsc-2026-amendments

WHY: Steph asked which building code the FLATS pod is built to and what Oregon changed. The 2026 Oregon Residential Specialty Code (ORSC) = the 2024 International Residential Code (IRC) + Oregon amendments; effective 2026-10-01, mandatory 2027-04-01 (https://www.oregon.gov/bcd/codes-stand/pages/orsc-adoption.aspx). The integrated codebook is not published yet and BCD's "summary of amendments" is "coming soon", so we build the list ourselves. docs/followups/71-building-code-editions.md has what is known (a BCD "26orsc-matrix" names R302.1 and R302.3 changes). The FLATS product: 4 attached two-storey townhomes (flats/config/pods/*.yaml -- read them), flat roof, factory-built panelized, rear parking court, sometimes each home on its own lot in a row.

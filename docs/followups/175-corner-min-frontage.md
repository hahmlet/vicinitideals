# 175. Corner-lot minimum frontage checked against both streets added together

From corner-frontage research 2026-11-09 (../vicinitideals-worktrees/corner-frontage.findings.md). Minimum lot frontage on a
corner lot is compared with both street lines plus the whole curve. Gresham 40 ft (25/32 ft townhouse) reads as a single-street
rule. Rough pass: ~16 GREEN corners (Gresham 11) whose shorter street alone is under the minimum. Which street the rule means is
not settled -> conservative: if the shortest street line alone fails and the code does not say 'combined', YELLOW with a flag
(RED only if every street alone fails and the code names the front). Side check: some RED rows show parking at exactly 50% vs a
50% cap with nothing short -- rounding?
